# Auntor Chakma — Portfolio

React + Vite portfolio. One file per section under `src/components`, data
separated under `src/data`, reusable SVG charts under `src/lib`.

## Run locally
```
npm install
npm run dev
```

## Build for deployment
```
npm run build
```
Deploy the generated `dist/` folder to Netlify or Vercel. The included
`netlify.toml` sets the SPA redirect so project pages load on refresh.
